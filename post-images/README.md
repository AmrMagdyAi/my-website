# Post images

Approved LinkedIn post images, named as the posting calendar names them
(content/linkedin-calendar.md in the project files). The scheduled posting
queue downloads them by name from here, since it can't read folders on the Mac.
Not linked from any page.

The g-*.png files are the new-style guide posts (Dec 16 to Feb 18), named as
fill-in-posts-2026-11.json names them.
