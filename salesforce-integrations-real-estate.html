Salesforce integrations for real estate investors.

Salesforce connects to almost every tool investors use, including DocuSign, QuickBooks, RingCentral, Gmail, Facebook lead ads, Google Ads and Slack, through AppExchange packages, the API or tools like Zapier. Below: what each connection syncs, which edition it needs, and what it changes for a wholesaling team.

Short version
  • Most investor tools connect to Salesforce through an AppExchange package or the API. The API is on by default only in Enterprise, Unlimited, Performance and Developer; Professional needs an add-on. Check this first. source
  • The connections that change results most for wholesalers: phone and text logging, lead source capture, e-signature on the deal and accounting for assignment fees.
  • Open CTI, which many dialers use inside Salesforce, reaches end of life on February 28, 2028. Ask any dialer vendor what their plan is. source
  • Zapier and Make are fine for one-way hops. For two-way sync (accounting) or in-app features (click to dial, signing), use a native package.

What do you need before connecting anything?

1. API access

Salesforce says API access is enabled by default in Enterprise, Performance, Unlimited and Developer, and that Professional can add it as an add-on. CallRail, Calendly, Dialpad, Aircall and Google Ads all depend on it, and Calendly says Group and Professional editions “cause errors.” source · Calendly

2. A dedicated integration user

Each connection should log in as its own user with only the permissions it needs, so you can see what it changed and switch it off without breaking anything else. Salesforce offers an API-only Integration user license for system-to-system connections. source

3. Fields that the integration writes to

Decide where each value lands before you install: call outcome, lead source, GCLID, contract status, invoice status. If the field doesn’t exist, the data ends up in a note nobody reports on. The CRM field kit has the core list.

4. A test in a sandbox (when the connector supports it)

Google’s Salesforce conversion import does not support sandboxes, so test that one with a single campaign in production. source

5. Token limits

Zapier notes that Salesforce allows 5 access tokens per account across third-party apps, and a sixth silently revokes the oldest. Another reason to give each integration its own user. source

Tool by tool: what each integration does for an investor

DocuSign: contracts signed from the deal

Docusign’s own package sends agreements from Salesforce using templates that pull record fields through merge fields, and writes signed documents and signer data back to Salesforce. Salesforce lists it as working with Professional, Enterprise, Unlimited, Developer, Starter and Performance. For a wholesaler that means the purchase agreement and the assignment contract go out from the same deal record, and the signed copies stay there. source · Full DocuSign guide

QuickBooks: assignment fees you can report on

The common QuickBooks connectors are third party: Breadwinner and DBSync (packages) or Workato (integration platform). Breadwinner creates invoices from Opportunities, Accounts or custom objects and tracks paid, overdue and due status. DBSync maps Opportunity to Invoice, Sales Receipt or Credit Memo. Breadwinner · DBSync · Full QuickBooks guide

Gmail and Outlook: no more copy-pasting emails

Salesforce’s Gmail and Outlook integrations add a side panel to log emails and create records. Einstein Activity Capture syncs contacts and events automatically. Salesforce for Outlook, the old desktop plug-in, retires in December 2027. source

Dialers: every call on the lead

RingCentral supports Professional and above; Aircall and Dialpad require Enterprise or Unlimited. All log calls to Salesforce records. Several, including RingCentral and Twilio Flex, use Open CTI, which ends February 28, 2028, with Salesforce Voice as the recommended replacement. RingCentral · Aircall · Dialpad · Full dialer guide

Texting: compliant before it’s fast

Twilio states that anyone sending app-to-person texts over a 10DLC number to the US must register for A2P 10DLC. Salesforce’s own messaging retired its standard SMS channels on February 14, 2026, and US long code registration takes 1–4 weeks. Twilio · Salesforce · Full texting guide

Lead sources: every lead tagged where it came from

Web-to-Lead takes up to 500 leads a day from your website. Lead Capture imports Facebook lead forms (Professional and up). Google’s Conversion Import for Salesforce sends stage changes back to Google Ads, so ads optimize toward contracts. CallRail sends call data only; texts and form fills don’t reach Salesforce. Web-to-Lead · Facebook · Google Ads · CallRail · Full lead sources guide

PropStream and BatchData: lists and skip tracing

PropStream exports lead lists as a spreadsheet; I found no Salesforce integration on its pages. BatchData offers a skip tracing API that returns phones flagged mobile or landline, plus DNC and TCPA litigator checks, but no Salesforce connector, so connecting it is a custom callout or middleware job. PropStream · BatchData

Google Drive, OneDrive and Box: one folder per deal

Salesforce Files Connect lets users browse and share files from Google Drive, SharePoint/OneDrive and Box inside Salesforce. Box for Salesforce adds a Box folder on each record. Files Connect · Box

Slack: the team hears about contracts instantly

Salesforce builds the current Slack apps, including Sales Cloud for Slack, Approvals in Slack and Flow actions that post to channels. source

Calendly: walkthroughs booked onto the lead

The Calendly package creates or updates Salesforce records when someone books; if it can’t match an email it creates a new lead. It requires Enterprise or higher and a Calendly Teams plan or above. source

Salesforce Maps: driving for dollars from your own data

Plots records on a map with routes, territories and nearby search. It’s an add-on, bundled in Agentforce 1 Sales. source

Email marketing: buyer blasts that report back

Account Engagement syncs with Professional and higher every 2–4 minutes. Mailchimp’s current Salesforce integration is built by Beaufort 12. Account Engagement · Mailchimp

What should a wholesaling team connect first?

1. Phone and text

Most seller conversations happen here. If calls and texts aren’t on the lead, nothing downstream (follow-up, reporting, coaching) works.

2. Lead sources

Web forms, Facebook, PPC and call tracking, each tagged with a source. Without this you can’t compute cost per deal.

3. E-signature

Contracts on the deal, and a signed contract moving the stage.

4. Accounting

Once deals close regularly: assignment fees invoiced from the deal, so reports show realized revenue.

5. Everything else

Slack alerts, maps, buyer email, scheduling. Useful, but they don’t fix a leak by themselves.

Questions

Does Salesforce integrate with DocuSign?

Yes. Docusign publishes Docusign eSignature for Salesforce on AppExchange. It sends agreements from Salesforce records using templates with merge fields and writes signed documents back. It needs a separate Docusign subscription.

Does Salesforce integrate with QuickBooks?

Yes, commonly through third-party connectors such as Breadwinner, DBSync or Workato, or through Zapier. They sync invoices, payments and customers between QuickBooks Online and Salesforce.

Which Salesforce edition do I need for integrations?

Many connectors need API access, which is included in Enterprise, Unlimited, Performance and Developer, and is an add-on for Professional. Some, such as DocuSign and RingCentral, also work on Professional. Check each vendor’s requirements.

Can I connect PropStream to Salesforce?

I found no native PropStream integration with Salesforce. PropStream exports lists as spreadsheets, which you can import with the Data Import Wizard (up to 50,000 records at a time) or Data Loader.

What is happening to Open CTI?

Salesforce says Open CTI reaches end of life on February 28, 2028, and existing implementations stop working after that. Salesforce Voice is the recommended replacement. Dialer vendors that use Open CTI need a new path.

Is Zapier enough to connect my real estate tools to Salesforce?

For simple one-way steps, often yes. For two-way sync, in-app features like click to dial, or near-instant updates, a native package is usually the better fit.
